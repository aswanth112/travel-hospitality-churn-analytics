# Travel Hospitality Chain Analysis

## 📌 Project Overview

This project focuses on analyzing hospitality booking data to understand customer behavior, booking patterns, booking cancellations, and business trends. The project involves data cleaning, exploratory data analysis (EDA), machine learning model development, and interactive Power BI dashboard creation to generate actionable business insights.

---

## 🎯 Objective

- Clean and preprocess raw hospitality booking data.
- Analyze customer booking behavior and cancellation patterns.
- Build machine learning models to predict booking cancellations.
- Create interactive Power BI dashboards for business decision-making.
